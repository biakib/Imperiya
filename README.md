# Империя

Карта проектов и людей.

- web/: клиент и оригинальные фотографии.
- worker/: сервер совместного редактирования с R2.
- scripts/: сборка Worker.

GitHub Pages размещает только клиент. Для совместного редактирования нужен сервер Worker с R2 и переменной MAP_OWNER_KEY. Ключи доступа не входят в архив.
